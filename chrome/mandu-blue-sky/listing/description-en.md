# Mandu Blue Sky

A giant golden pixel-art dumpling peeks over a rolling green hill beneath a bright blue sky. Its red glasses and tiny neutral expression bring a playful detail to every New Tab

The browser palette follows the scene: soft sky-blue frames, a cloud-white toolbar, and a pale-blue address bar with deep-blue controls

## Features

- Original 1920×1080 New Tab artwork with a photographic landscape and pixel-art character
- Sky-blue tabs and a light toolbar
- Top-right background alignment with no tiling
- A matching golden character icon

Chrome displays theme backgrounds at their native size. The visible crop varies with window size, display scale, and browser zoom. Larger windows can show the sky-blue fallback color beyond the image

## Access and privacy

This theme only changes browser colors and the New Tab background. It contains no scripts, requests no permissions, and collects no data
