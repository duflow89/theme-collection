# 크롬 웹 스토어 등록 안내

## 제품 세부정보

| 항목 | 입력값 |
| --- | --- |
| 제목 (Title) | `안경만두의 파란 하늘` |
| 요약 (Summary) | `파란 하늘과 초록 언덕 위로 떠오른 안경만두의 원작 이미지를 담은 비공식 크롬 테마` |
| 설명 (Description) | [description-ko.md](description-ko.md) 전체 내용 복사 |
| 카테고리 (Category) | `Just for Fun`에 해당하는 항목 |
| 언어 (Language) | `한국어 (Korean)` |

상세 설명 파일은 대시보드에 바로 붙여넣을 수 있는 일반 텍스트 형식이며, 원작자와 두 출처 링크를 포함

## 기존 초안을 한국어로 변경

1. 기존 `Mandu Blue Sky` 초안의 **패키지** 메뉴에서 `mandu-blue-sky-v1.0.1.zip` 업로드
2. 패키지 제목이 `안경만두의 파란 하늘`로, 요약이 한국어로 바뀌었는지 확인
3. **스토어 등록정보**의 **설명** 칸에 [description-ko.md](description-ko.md) 전체 내용 입력
4. **언어**에서 **한국어** 선택
5. 아래 이미지 업로드 후 **임시저장**

ZIP 업로드로 제목과 요약을 반영할 수 있으나, 상세 설명·카테고리·언어·홍보 이미지는 대시보드에서 별도 등록 필요
