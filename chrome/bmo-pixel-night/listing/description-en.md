# BMO Pixel Night

Bring a cozy pixel-art night to your browser with BMO Pixel Night, an unofficial fan-made Chrome theme inspired by BMO

This theme combines a mint-green retro game console character with deep navy browser frames, soft teal toolbars, warm pixel lighting, and a peaceful nighttime gaming room. The New Tab background is designed with plenty of dark space so that search, shortcuts, and browser controls remain easy to see

Features:

- A cozy 2D pixel-art New Tab background
- Deep navy tabs and browser frame
- Mint and teal accent colors inspired by a retro game console
- Clear, high-contrast text and browser controls
- No scripts, tracking, advertising, or data collection

BMO Pixel Night is made for anyone who enjoys pixel art, retro games, cozy nighttime scenes, and playful browser customization

This is an unofficial fan-made theme. It is not affiliated with, sponsored by, or endorsed by the original creators or rights holders. All related character names and intellectual property belong to their respective owners
