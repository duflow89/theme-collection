# BMO Pixel Night

BMO에서 영감을 받아 제작한 비공식 팬 메이드 Chrome 테마로, 브라우저에 포근한 픽셀아트 밤 풍경을 더하는 테마

민트색 레트로 게임기 캐릭터, 짙은 네이비색 브라우저 프레임, 부드러운 청록색 툴바, 따뜻한 픽셀 조명과 평화로운 밤의 게임방을 조합한 구성. 새 탭 배경 중앙에는 충분한 어두운 여백을 두어 검색창, 바로가기, 브라우저 컨트롤의 가독성 확보

주요 특징:

- 포근한 분위기의 2D 픽셀아트 새 탭 배경
- 짙은 네이비색 탭과 브라우저 프레임
- 레트로 게임기에서 영감을 받은 민트·청록색 포인트
- 읽기 쉬운 고대비 텍스트와 브라우저 컨트롤
- 스크립트, 추적, 광고 및 데이터 수집 없음

픽셀아트, 레트로 게임, 아늑한 밤 풍경과 개성 있는 브라우저 꾸미기를 좋아하는 사용자를 위한 테마

비공식 팬 작품이며 원작 제작자 또는 권리 보유자와 제휴하거나 후원·승인받은 제품이 아님. 관련 캐릭터 이름과 지식재산권은 각 권리 보유자에게 귀속
