# BMO Pixel Night 설치 방법

개인용 비공식 Chrome 팬 테마

1. Chrome 주소창에서 `chrome://extensions` 열기
2. 오른쪽 위 `개발자 모드` 활성화
3. `압축해제된 확장 프로그램을 로드합니다` 선택
4. 이 `bmo-pixel-night` 폴더 선택
5. 새 탭을 열어 테마 확인

테마 제거 또는 기본값 복원은 `chrome://settings/appearance`의 `기본값으로 재설정` 사용

ZIP 파일을 받은 경우 먼저 압축을 푼 뒤 위 절차 진행

## 배경 표시 참고

- 새 탭 배경은 화면 하단 중앙 정렬
- 배경 이미지 규격은 `2560×1440` RGB PNG
- Chrome 테마 형식은 배경 크기의 `cover` 또는 `contain` 설정을 지원하지 않음
- 브라우저 확대·축소 수준과 창 크기에 따라 배경이 보이는 범위가 달라질 수 있음
