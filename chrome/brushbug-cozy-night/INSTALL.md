# Install Brushbug Cozy Night

An unofficial Chrome fan theme for personal use

1. Open `chrome://extensions` in the Chrome address bar
2. Enable `Developer mode` in the upper-right corner
3. Select `Load unpacked`
4. Select this `brushbug-cozy-night` directory
5. Open a New Tab to verify the theme

To remove the theme or restore Chrome defaults, select `Reset to default` under `chrome://settings/appearance`

If you received a ZIP file, extract it before following the steps above

## Background display notes

- The New Tab background is aligned to the bottom center
- The background image is a `2560×1440` RGB PNG
- Chrome themes do not support `cover` or `contain` background sizing
- The visible background area can vary with the browser zoom level and window size
